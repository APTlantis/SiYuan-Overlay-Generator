# Success Criteria — SiYuan Project Exploration Overlay Generator v0.1.0

v0.1.0 is complete when:

- An arbitrary representative project can be scanned without source mutation.
- A normalized project model is created before output projection.
- The generated package imports through the supported portable SiYuan path.
- The project root provides immediate orientation.
- Directory surfaces explain and index their contents.
- Supported text/source files are readable.
- Unsupported and binary artifacts receive safe metadata-only representations.
- Project resources are discoverable through portable generated indexes.
- Snapshot provenance is explicit.
- At least one structure visualization is useful.
- CLI behavior is documented and automation-detectable under CTS.
- Representative verification demonstrates that the overlay is materially more useful than a plain imported hierarchy.

## Completion vs. Evolution

Only missing, broken, contradictory, unsafe, or unverified items required above lower v0.1.0 completion.

Future capabilities such as native SiYuan structures, AI summaries, refresh, dependency analysis, and multi-project views are evolution findings and do not lower completion.
